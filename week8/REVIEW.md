## Deliberate choices

* **Interference-to-signal ratio.** For the matrix stores the recall is written
  as `c_j v_j + leak` with `c_j = v_j . f`; for the ReLU and softmax stores the
  recall is divided by the matching weight first. Without the projection the
  least-squares store's capacity comes out 33/65/133 rather than 1e14/1e14/1e14:
  past `d` memories its answer is a shrunken mixture of all the values and only
  the coefficient of `v_j` is the signal.
* **Queries.** Each draw queries 32 stored keys chosen at random and the ratios
  are pooled before the median. Querying a single key per draw is what makes the
  outer-product series non-monotone above 30 000 memories.
* **Smoothing.** k is chosen on the last 10% of the *training* tokens, never on
  validation, so the held-out numbers stay honest.
* **Scaling-law L-BFGS.** The default `gtol` of `scipy.optimize.minimize` stops
  the bootstrap refits in a flat region: standard errors come out about six
  times too small (alpha ±0.002 instead of ±0.014). With `gtol = 1e-12`,
  `ftol = 1e-14` the errors match the replication.
* **MLP batch size.** 16 384 examples per step, as the prompt asks. At 512 the
  gradient noise leaves the model 0.02 nats above the bigram, reproducing the
  sheet's own remark.

## Code ownership notes

`CountSet` owns the packed int64 count tables and exposes `distribution`,
`probabilities`, `nll` and `unseen_fraction`; every consumer (the ladder, the
sampler test, the transformer comparison) goes through those four methods.
`transformer.py` owns the parameter tree; `train_transformer.py` adds `flatten`
and `unflatten` so a trained model can be re-scored without retraining, which is
what `--resume` uses. The samplers in `samplers.py` all return a full probability
vector, so the exact target of each sampler is available for the chi-squared test
instead of being re-derived in the test.
